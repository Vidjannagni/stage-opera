Comment le classement est calculé

Le cabinet ne fixe pas de seuil de rentabilité : un même bien peut être bon pour un client et mauvais pour un autre. Le classement n'est donc pas une note absolue. Chaque critère est ramené entre le meilleur et le moins bon des montages de cette étude, puis pondéré selon l'objectif déclaré du client. Un score n'a de sens qu'à l'intérieur de cette page.

Les montages sont construits sur une règle de financement explicite : une banque prête sur le bien, pas sur les frais. L'apport minimal d'un dossier est donc la somme des frais d'acquisition et des travaux. Les taux proposés suivent la durée ({% for duree, taux in hypotheses.TAUX_PAR_DUREE.items() %}{{ duree }} ans : {{ taux | pourcent }}{{ ", " if not loop.last }}{% endfor %}), l'assurance {{ hypotheses.TAUX_ASSURANCE | pourcent }} — toutes ces valeurs sont modifiables sur un scénario enregistré.
